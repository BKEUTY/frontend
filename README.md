<a name="english"></a>
## English - Frontend Architecture

### 🌟 Executive Summary
BKEUTY Storefront is a high-end customer-facing ecosystem comprising a **Progressive Web Application (PWA)** and a **Native Mobile Application**. It is designed with a "Luxury First" philosophy, providing a seamless and high-performance shopping journey.

### 🛠 Core Technologies
- **Web App:** React 19, Vite, Tailwind CSS, Ant Design 6.
- **Mobile App:** React Native, Expo SDK 50+, React Navigation 7.
- **State Management:** TanStack Query 5 (Server State), React Context (UI State).
- **Communication:** Axios with Global Interceptors for JWT handling.

### 🚀 Key Features
- **Sophisticated Discovery:** Smart search and multi-criteria product filtering.
- **Unified Commerce:** Real-time synchronization of carts and orders across devices.
- **Return Management:** End-to-end return request workflow with multi-image support.
- **Global Identity:** Single Sign-On (SSO) integrated with Keycloak (OAuth2).

### 🚦 Development & Ports
| Platform | Environment | Port | Startup Command |
| :--- | :--- | :--- | :--- |
| **Web Store** | Development | 3000 | `npm run dev` |
| **Mobile App** | Expo Metro | 8081 | `npx expo start` |
